## 固定交付

两特产、两城四配方、目标供货与补给缓冲、同源整包混装、双端容量预留、两种车辆改装、CM04–CM06九阶段、F05/F06两种首访及两条有限线索/普通复访、L03四节点、三份档案复原、P11较灵活的达成证明、运输及候车/听雨间/修车棚街景、结构1–5迁移和旧规则离线桥接。保留前三章和前两批全部功能。分所/历法/公约不在本批。

胶片和轨芯是有限章节材料：调查、委托、改装、收藏完成后正常停产。按剩余用途显示目标建议和可收拢配置，不增加每日消耗、每日任务或永久特产税。

## 配方、容量和整包货单

全部采用内部1000表示1单位的定点数。两城每60秒整份生产；缺料或产物空间不足时保留就绪周期。切换模式需明确确认，清空最多60秒周期，不扣未消耗材料；库存与在途货物不变。

| 城市/模式 | 每周期投入 | 产出 |
| --- | --- | --- |
| 雨城常规整理 | 10电量、20零件 | 12记忆 |
| 雨声封装 | 10电量、12零件 | 2胶片 |
| 长站旧轨回收 | 12电量、8记忆 | 32零件 |
| 轨芯整备 | 12电量、6记忆 | 2轨芯 |

对应线路开放即可选特产模式，无自锁前置。本城两特产各容量`12 + 4 × 全城仓库总等级`；外城对应特产24，其他城市不接收该特产。构件仍留本城。基础资源容量不变。

去程为当前所选配方的补给包；回程雨城有12记忆/2胶片两种包，长站有32零件/2轨芯两种包。同源回程可混装，每种数量0–32、至少一包，去程只装选定模式补给。合计资源单位不得超过单车40/研究后80、强化货架后60/100。旧1/2份操作仍对应相同普通货单。

运单固定货物、配方、时长、费用、磨损和是否持有预留；后续模式、合同或改装不能改写。新车在目的地预留整车空间：库存+其他预留+本次货物≤总容量。生产、奖励、其他到货与拆仓遵守预留；卸货原子释放预留并增加库存，预留不算物资收入。旧无预留车仍可满仓等待；它不能抢占新车已预留的空间。

## 目标合同

每条线路分别设置普通产物/特产目标、本城六资源保留量、补给缓冲1–8周期（默认2）、回程两类整包数量与顺序。每类0–32包，至少一种；目标与保留量为0–1,000,000、最多三位小数。模板“补本城原料”以普通产物容量为目标；“取城市特产”推荐特产6。新线路通车时初始化普通产物目标为本城容量；旧合同保留启用、优先级、1/2份、最低库存，在旧区间结算后初始化同一目标。玩家随后保存的双零目标是有效停供配置，切页、重开及修改其他字段均保留，不再推断为未配置。

按线路优先级使用共享车辆：先继续旧运输与卸货；未达目标时按缺口、玩家包数上限、货单顺序、实际来源库存、车容和可预留空间取回，允许最后一包超过目标。不能为了凑齐另一类货物让可发货物等待。否则只在当前模式产物仍有需求、外城不足缓冲时，按配方送一车补给。另一种产物只顺带取现存库存，不自动换模式。目标满足时待命；消耗目标物资后恢复。保留线包含发车电量。暂停只停已保存合同，不提交无效草稿。

## 车辆

蓝图全网通用、制作共用工务队列；每方案4构件、2轨芯、20电量、120工程点，各制作一次，完工不自动启用。全网单启用位；存在途中或待卸车时不能切换，暂停合同不会取消货物。

- 强化货架：运量+20，每次发车额外2电量。来源CM04-1或F06扩写运单。
- 护轨挂架：发车磨损×0.75后向上取整，运量维持基准。来源CM06-1或F06更换旧接头。
- E12稳班80磨损/标准时长；快班150磨损/0.8时长继续有效。护轨对应60/113磨损，先组合再取整。

## 结构6与离线桥接

迁移标记旧规则待结算；控制器取得写入权后固定当前时点，在此之前的未结算区间按V0.3.2运输/合同/目标条件推进，不能用新规则回算特产或预留。纯引擎不读系统时钟；结算完成后在显式时点启用新规则，此后新车持有预留。长结算中断可从原有效存档重试；导入/恢复同样桥接。存储键、备份与写入锁不变。
