## 1. 使用方式与参与边界

先完成第4节的环境与存档检查，再只向玩家提供第2节。第3、5–9节由主持人私下使用，不提前展示答案、成功比例、推荐路线或预期问题。

- 首轮安排5–8位未参与开发的独立参与者，以P01–P08记录；同一个人参加多段仍只算一人。样本用于发现问题，不估算留存率，不宣称统计显著。
- 参与自愿，可随时暂停、跳过问题或结束；不以完成章节为报酬、认可或继续参与的条件。发生不适、误入个人数据环境或存档风险时停止该段。
- 只收集匿名编号、必要的设备/浏览器信息、游戏行为与自愿反馈；不收集姓名、联系方式、账号、精确位置或其他无关个人信息。习惯只记录“偏持续操作／偏安排后离开／不确定”。
- 默认使用去身份化的文字笔记，不录音、录屏或拍摄玩家。任何额外记录或对外共享需另行取得明确同意；不同意不影响试玩。不要记录其他应用、通知或个人标签页。
- 由已获授权的组织者自行安排参与；本文不授权自动招募、发送消息、注册服务、上传记录或公开参与者资料。
- 原始观察由组织者保存在其选定的本地受控位置；本仓库只适合放经确认的匿名摘要。开场前明确本次笔记用途、查看范围和保留安排，未确定则先不采集。撤回记录按已告知的安排处理，不为追踪撤回而补采联系方式。

## 2. 可提供给玩家的说明

### 开场与同意

> 感谢你愿意试试《第0街区》。我们想了解游戏哪些地方容易理解、哪些地方让人犹豫，不是在考你，也没有正确玩法。请按自己的想法操作；愿意的话，可以说出你正在想什么，不想说也没关系。
>
> 第一段从一个新的游戏进度开始，约20–30分钟；随后离开游戏约15分钟，再回来看看。今天若另有章节专题，会在开始前说明时长，你可以选择不参加。任何时候都可以停下、休息或跳过问题。
>
> 我们只用匿名编号记录游戏中的操作和你愿意分享的想法，不需要姓名、联系方式或账号。本次默认不录音、不录屏。主持人会先说明笔记用途、谁能查看和保留安排。你是否愿意按这个方式参加？

仅在同意后开始记录。不同意则结束，不登记个人信息。

### 新进度探索

> 这里是一段新的游戏进度。请按你自己的想法玩，做你想做的事情；如果不知道该做什么，也可以直接说。你不必为了试玩一直操作，也不用在规定时间内通关。

不要另发功能清单、最短路线、资源配方或目标答案。玩家主动问到玩法时，主持人按第5节记录介入。

### 离开与返回

> 接下来请按自己的想法，决定离开前是否做一些安排。然后离开游戏约15分钟；期间不需要查看。回来后仍按自己的想法继续。

返回后先让玩家自行查看和操作。自然停顿时才问：

> 你现在觉得发生了什么？还有什么想处理？接下来准备怎么做？

### 可选章节专题

> 下面是一份已经玩到后续章节的真实游戏进度，不是你刚才的存档。它有之前玩家留下的安排与选择。你可以先查看，再选择自己想继续做的事情；看不懂已有安排也可以直接说。这一段与刚才的新手体验分开记录。

如需补充指定路线的功能观察，先结束自然探索，再明确告知“接下来是指定任务，不再用于判断你是否会自行发现目标”。不把指定任务伪装成玩家自发选择。

## 4. 主持人准备：版本、真实存档与保护

### 4.1 使用隔离的试玩空间

1. 首选独立浏览器配置或专用测试设备。若手机不便建立配置，使用确认没有个人《第0街区》进度的专用浏览器环境；无法确认隔离时不要导入。不要清除站点数据、重置个人进度或删除其他浏览器资料。
2. 记录实际地址、页面“设置”中的游戏/数值/结构版本及设备环境。可从[已发布试玩入口](https://lxjmaster.github.io/DistrictZero/)开始，但以会话当天实际显示为准；中途换版本则拆分记录。当前文档适用结构6／数值0.3.3。
3. 新档段开始前确认没有已有玩家进度；不以“重置本地进度”清空个人存档来获得新档。同一地址只开一个承担试玩的游戏页，避免第二页只读或接管干扰。
4. 保存位置随浏览器、设备及网站来源而不同；本地不同端口也不同。换环境前使用游戏“导出存档”，并保留原文件。普通标签页不是隔离环境；隐私窗口关闭后可能丢失进度，不适合未经验证的离开重开流程。
5. 核心段与专题使用不同的隔离配置，或先导出核心段且确认文件可读取后，仅在明确的测试进度中替换。恢复副本会随后续保存变化，不能代替独立导出文件。
6. 只通过“设置 → 选择存档文件／存档文本 → 检查存档 → 确认导入并替换”导入。先核对检查摘要和目标环境；检查失败时记录报错，不修改JSON（结构化文本）绕过检查。
7. 专题前由主持人完成导入和历史离线补算，记录补算完成后的实际起点，再交给玩家。历史文件带旧时间，库存、在途车和队列可能因补算变化；文件原始状态不等于今天导入后的状态。不改`savedAt`、游戏时间、资源、分支或系统时钟，也不使用自动化加速真人等待。
8. 主持人需要通过正常操作准备某个场景时，单独记录每次准备与实际导出状态，明确这不是玩家行为。准备过的档不能再测已被主持人完成的发现、选择或章末达成；本包未生成这类新档。
9. 结束前由参与者决定是否保留自己的试玩进度；只处理确认属于本次的资料，不删除个人或共享资源。存档与匿名记录默认不上传、不自动发给他人。

导出建议名为`P01-新档-离开前.json`、`P01-新档-返回后.json`等，仅用匿名编号。每段保留起止版本、实际时刻、起点导出及终点导出；没有得到保存记录同意时只留文字摘要，并明确证据限制。

## 5. 主持人执行流程与提示分级

### 5.1 核心段：新档、离开、返回

| 时点 | 主持人行为与非诱导问题 | 记录边界 |
| --- | --- | --- |
| 开始前 | 完成同意、隔离和版本记录；先约定新档20或30分钟，默认30分钟 | 不先讲构件、改装、哪种选择更好；没开局不算样本 |
| 新档0–20/30分钟 | 观察为主。自然停顿时可问“你现在想做什么？”“刚才为什么这样选？” | 不按固定频率打断；记录问题时刻。询问后出现的想法与此前自发目标分开 |
| 首次犹豫、停工或主动离开意向 | 先记行为，待自然停顿再问“你现在是在等什么，还是想先做别的？” | 不把沉默直接判断为无聊；分别记录玩家意愿、可见停因和主持人推测 |
| 新档段结束 | 先问“如果继续玩，你现在想做什么？为什么？”再请玩家自由回顾所用资源和选择 | 此时冻结自主目标时间线；之后的专题问答不倒算进首30分钟 |
| 随后的理解问答 | 先开放问“刚才哪些材料或安排有用？你会在什么情况下换一种做法？”必要时再问“你怎样理解构件的用途，以及快速/节料两种方案的取舍？” | 只问不教、不展示答案；记录是否已自然接触相应界面。明确点名后的用途回答与此前自发提及分列 |
| 离开前 | 只读第2节离开说明，记录玩家自己的安排、预期与保存状态 | 不代配生产、不强制留待办、不承诺返回一定有奖励 |
| 实际离开约15分钟 | 记录离开/返回实际时刻及方式：关闭页、后台、锁屏或其他 | 不偷看或代操作。系统杀页、断网、实际时长偏差照实记录，不改时钟补齐 |
| 返回后先约2分钟 | 尽量不发问，让玩家先看、读、点；记第一个注意对象与第一动作 | 没有报告、暂未出现成果也是事实；不指向报告按钮或街景 |
| 返回自然停顿时 | 问“你现在觉得发生了什么？还有什么想处理？接下来准备怎么做？” | 记录未决事项、实际变化、下一安排及其依据；不能复述主持人刚教过的答案充当独立理解 |
| 最后约5分钟 | 问“你记得哪些人或事情？”再问“有哪个决定让你记得？后来有什么变化？”“哪一段你最想继续，哪一段最想停？” | 先自由回忆，不先报联系人姓名、选项或街景名；兴趣陈述不当长期留存证据 |

只做20分钟的参与者仍保留在本轮记录；其30分钟窗口是不完整观察，不能把未发生目标当作完整30分钟结果，也不能凭20分钟有目标声称后10分钟没有空档。真人阅读与思考不从耗时中剔除；暂停、环境故障、主持人教学另标区间。

### 5.2 提示等级

| 等级 | 定义 | 允许示例与结论限制 |
| --- | --- | --- |
| H0 | 无玩法提示；只读开场或开放式询问 | “你现在想做什么？”仍记提问时刻；只有玩家未获相关答案/位置帮助的表现才可作为不提示理解 |
| H1 | 非答案性重述或确认操作意图 | “你想确认的是现在能不能开始这件事吗？”之后记录为有轻度介入，不与纯H0混算 |
| H2 | 指出页面、入口或信息所在位置 | “可以看看这个面板显示的停止原因。”已帮助找入口，不能据此说入口可自行发现 |
| H3 | 解释规则、给出具体步骤、指定方案或主持人代操作 | 教完后能完成只能说明受助可完成；不计作自主目标或不提示理解 |

玩家求助或希望继续却卡住时可以提供帮助，不以收集长等待为由让人难受。先记录卡点、时长、意愿及已尝试操作，征得愿意接受提示后逐级介入；每次记录原话、原因和受影响的指标。没有求助也不机械等满5分钟才允许结束。

“超过约5分钟被迫盯条”的计时需同时有证据：玩家已掌握当前操作、本想继续玩、该区间只有等待且未找到可执行目标。主动离开放置、主动读故事、正常思考或主持人解释不算同一种空档；原因不明时写“证据不足”。
