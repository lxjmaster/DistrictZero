# 第0街区 · V0.6.1试玩入口

在线地址：https://lxjmaster.github.io/DistrictZero/

本页供自己试玩或交给已安排的参与者。没有规定路线或通关要求；想停时可以停。当前版本应显示V0.6.1、存档结构10，以当天设置页为准。真人采样目前仍按用户要求暂缓。

## 从新进度开始

在没有自己游戏进度的独立浏览器配置或专用环境中打开地址，按自己的想法玩约20–30分钟。随后按自己的想法安排一次离开，约15分钟后回来。真实等待即可。

如果已有进度，先在“设置”导出并保存文件。普通新标签页仍共用存档；不要为了试玩清除自己的进度，也不要在两个页面同时操作。

## 直接体验后续章节

压缩包内的`saves/`是真实自动化路线导出，保留原版字节和时间，包含以前留下的安排与选择。它们不是你的前情，也不是已取得的真人反馈。

| 文件 | 从哪里继续 |
| --- | --- |
| `02-city.json` | 第一章之后，继续夜城与地址 |
| `03-network.json` | 第二章之后，继续城际夜网 |
| `04-outposts.json` | 第三章及扩充内容之后，继续分所 |
| `05-calendar.json` | 分所之后，继续历法维修 |
| `06-covenants.json` | 历法之后，继续城市公约 |
| `05-prepared.json` | 已有安排的备料样本；仅供主持人另行安排操作专题 |

只在确认没有个人进度的环境中导入：**设置 → 选择存档文件 → 检查存档 → 核对摘要 → 确认导入并替换**。旧档会迁移到当前规则，历史时间会正常补算，库存或在途状态可能变化。等待结算完成后先导出一份实际起点，再开始本段观察。不要修改JSON或设备时钟来跳过等待。

主持人先留自然探索，再另行提出指定任务。不要把文件名中的章节当成已经在本段实际完成，也不要把过去的自动准备算作自主发现。`host-manifest.json`供主持人核对来源、原始时刻与SHA-256（文件摘要）。
